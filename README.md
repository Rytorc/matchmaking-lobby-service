# Matchmaking Lobby Service

A junior-friendly full-stack project with a C++ backend and React + TypeScript frontend for player matchmaking, lobby creation, and match result tracking.

## Tech Stack
- C++20
- Crow
- PostgreSQL
- React
- TypeScript
- Vite
- Docker Compose
- Jenkins

## Planned Features
- Register/Login
- Queue Join/Leave
- Matchmaking
- Lobby Creation
- Match Results
- Match History
